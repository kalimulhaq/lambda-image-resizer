# Contributing

Contributions are welcome!

1. Fork the repo and create a branch off `main`.
2. Set up your environment as described in the [Development](README.md#development) section of the README.
3. Make sure `ruff check .`, `ruff format --check .`, `mypy src/`, and `pytest --cov=src` all pass before opening a PR.
4. Add or update tests for any behavior change.
5. Open a pull request describing what changed and why.
